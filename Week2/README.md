
# ☁️ Week 2 — Cloud Platform (AWS Basics)

Welcome to Week 2 of the Master Class Program on Cloud Computing and DevOps.

This week focuses on cloud platforms, with an introduction to Amazon Web Services (AWS) and its core services. The training covers cloud computing providers, virtual servers, cloud storage, identity and access management, instance deployment, and basic cloud architecture.

## 📚 Topics Covered

- Introduction to cloud providers: AWS, Microsoft Azure, and Google Cloud Platform (GCP)
- Core AWS services: EC2 (Virtual Servers), S3 (Cloud Storage), and IAM (Users and Roles)
- Launching and managing EC2 instances
- Understanding key pairs and security groups
- Fundamentals of cloud architecture
- Launching an EC2 instance
- Hosting a simple website using AWS
- Uploading files to Amazon S3

## 🎯 Learning Objectives

By the end of this week, the documentation will cover:

- Understanding the roles of major cloud service providers.
- Learning the purpose of essential AWS services.
- Understanding how virtual servers are launched and managed.
- Exploring access control and instance security using key pairs and security groups.
- Understanding basic cloud architecture and website hosting.
- Learning how files are stored and uploaded using Amazon S3.
