
# Day 06 — Cloud Computing Fundamentals

**Training Date:** 07 July 2026

## 1. Overview

The sixth day of the Master Class Program on Cloud Computing and DevOps focused on the fundamentals of Cloud Computing and its importance in modern software development.

Cloud computing has transformed how organizations store data, deploy applications, and manage computing resources by providing services over the internet. The session covered cloud architecture, the key characteristics and benefits of cloud computing, an introduction to Amazon Web Services (AWS), web services, Service-Oriented Architecture (SOA), and different cloud service models.

## 2. Topics Covered

### 2.1 Introduction to Cloud Computing

Learned about the fundamental concepts and evolution of Cloud Computing.

- **Definition:** Cloud Computing is the delivery of computing resources and services, such as servers, storage, databases, networking, and software, over a network on demand.
- **Evolution of Cloud Technology:** Explored the development of computing from traditional infrastructure and centralized systems towards virtualized, scalable, and internet-based services.
- **Basic Cloud Architecture:** Studied how clients, networks, cloud infrastructure, storage, and application services work together to deliver computing resources.
- **Importance in Modern IT:** Understood how cloud computing supports application deployment, data storage, collaboration, and infrastructure management.

### 2.2 Characteristics of Cloud Computing

Studied the five key characteristics of cloud computing:

- **On-Demand Self-Service:** Users can provision computing resources when required without needing direct human interaction with the service provider.
- **Broad Network Access:** Cloud services are accessible over a network through supported devices and standard access mechanisms.
- **Resource Pooling:** Providers share computing resources among multiple customers using a multi-tenant model, while logically separating their resources and data.
- **Rapid Elasticity:** Resources can be scaled up or down according to changing demand.
- **Measured Service:** Resource usage is monitored and measured, supporting usage-based billing and resource management.

### 2.3 Benefits of Cloud Computing

Explored the major advantages of using cloud infrastructure instead of relying entirely on traditional on-premises systems.

- **Cost Efficiency:** Reduces the need for large upfront investments in physical infrastructure.
- **Scalability:** Allows computing resources to grow or shrink according to workload requirements.
- **High Availability:** Cloud services can use redundancy and multiple availability zones to improve service availability.
- **Flexibility:** Provides access to different computing resources according to application needs.
- **Reliability:** Backup, redundancy, and recovery mechanisms can help improve system reliability.
- **Automatic Updates:** Some managed cloud services handle updates and maintenance tasks.
- **Improved Collaboration:** Teams can access shared resources and applications from different locations.
- **Disaster Recovery Support:** Cloud storage, backups, and replicated infrastructure can support recovery after failures.

### 2.4 Introduction to Amazon Web Services (AWS)

Received an introduction to Amazon Web Services (AWS), a cloud computing platform that provides a wide range of infrastructure and application services.

Topics covered included:

- The meaning and purpose of AWS.
- Advantages of using AWS for cloud-based solutions.
- Popular AWS services for computing, storage, databases, and access management.
- Reasons organizations use AWS to deploy applications and manage infrastructure.

AWS enables organizations to provision computing resources on demand rather than managing all physical infrastructure themselves.

### 2.5 Services and Web Services

Learned the concept of services and how web services enable communication between different applications over a network.

- **Service:** A software component or system that provides a specific capability to other users, applications, or systems.
- **Web Service:** A software interface that enables applications to exchange data or invoke functionality using network-based protocols and defined interfaces.

Web services help different applications communicate even when they are developed using different programming languages or technologies. This improves interoperability and supports integration between distributed systems.

### 2.6 Service-Oriented Architecture (SOA)

Studied Service-Oriented Architecture (SOA), an architectural approach in which applications are organized around independent and reusable services.

Key concepts included:

- **Reusability:** A service can be used by multiple applications or business processes.
- **Loose Coupling:** Services are designed to minimize unnecessary dependencies on one another.
- **Interoperability:** Services can communicate across different systems and technologies through defined interfaces.
- **Maintainability:** Individual services can be updated or maintained without redesigning the entire application, provided their interfaces and dependencies remain compatible.
- **Scalability:** Services can be managed and scaled according to their individual requirements.

SOA is useful in distributed environments where multiple systems need to communicate and share functionality.

### 2.7 Cloud Platforms

Explored different cloud platforms used to develop, deploy, and manage cloud-based applications.

The session introduced cloud platforms that provide computing, storage, networking, and application services. These platforms help organizations reduce the complexity of managing physical infrastructure and support flexible application deployment.

### 2.8 Cloud Service Models

Studied the major cloud service models and how responsibility is divided between the cloud provider and the customer.

#### A. Infrastructure as a Service (IaaS)

IaaS provides fundamental computing infrastructure through services such as virtual machines, storage, and networking.

- Users can provision and configure virtual infrastructure.
- Customers generally manage the operating system, applications, and relevant configurations.
- It offers flexibility and control over computing resources.

**Example:** Amazon EC2.

#### B. Platform as a Service (PaaS)

PaaS provides a platform for developing, testing, and deploying applications without requiring users to manage the underlying infrastructure in the same way as IaaS.

- Simplifies application development and deployment.
- Reduces infrastructure administration.
- Allows developers to focus more on application code.

#### C. Software as a Service (SaaS)

SaaS delivers ready-to-use software over a network, usually through a web browser or application.

- The provider manages the application and its underlying infrastructure.
- Users access the software without managing the server environment.
- Updates and maintenance are generally handled by the provider.

**Examples:** Google Workspace and Microsoft 365.

#### D. Function as a Service (FaaS)

FaaS allows developers to run individual functions in response to events without directly managing the underlying servers.

- Functions execute when triggered by events or requests.
- Infrastructure provisioning and scaling are largely handled by the provider.
- It supports event-driven and serverless application architectures.

**Example:** AWS Lambda.
