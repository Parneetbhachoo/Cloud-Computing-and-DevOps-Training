## 📖 About This Repository

Welcome to my **Cloud Computing and DevOps Training Diary**!

This repository documents the learning journey and practical activities undertaken during the *Master Class Program on Cloud Computing and DevOps*. It serves as a structured record of the concepts studied, tools explored, practical exercises performed, and skills developed throughout the training.

The diary is organized week by week, with individual Markdown files documenting daily learning objectives, theoretical concepts, practical implementations, commands, outputs, challenges, and key takeaways.

## 🎯 Training Objectives

- Understand the fundamentals of Cloud Computing and DevOps.
- Develop familiarity with Linux, networking, and shell scripting.
- Explore cloud services and infrastructure using AWS.
- Learn version control and collaborative workflows using Git and GitHub.
- Understand Continuous Integration and Continuous Delivery (CI/CD).
- Gain practical exposure to Jenkins, Docker, and containerization.
- Understand the workflow involved in deploying applications to the cloud.

## 🗂️ Training Curriculum

### 🐧 Week 1 — Linux, Networking & Fundamentals

- Introduction to Cloud Computing and DevOps
- Linux fundamentals: file systems, permissions, and users
- Shell scripting and basic automation
- Networking: IP addresses, DNS, ports, HTTP, and HTTPS
- Virtualization and Ubuntu virtual machine setup
- Network commands: `ping`, `netstat`, and `curl`

📁 **[Explore Week 1](Week1/README.md)**

### ☁️ Week 2 — Cloud Computing & AWS Basics

- Overview of AWS, Azure, and Google Cloud Platform
- AWS EC2, S3, IAM users, and roles
- Launching and managing EC2 instances
- Key pairs and security groups
- Basic cloud architecture
- Website hosting and file uploads using S3

📁 **[Explore Week 2](Week2/README.md)**

### ⚙️ Week 3 — Git, GitHub & CI/CD

- Version control using Git
- Creating and managing GitHub repositories
- Git workflows: clone, commit, push, and pull requests
- Introduction to Continuous Integration and Continuous Delivery
- Jenkins fundamentals and pipeline setup
- Build process automation

📁 **[Explore Week 3](Week3/README.md)**

### 🐳 Week 4 — Docker & Deployment

- Introduction to Docker images and containers
- Dockerfiles and container deployment
- Understanding the DevOps lifecycle
- Application deployment using GitHub, Docker, and AWS
- Fundamentals of CI/CD pipeline integration

📁 **[Explore Week 4](Week4/README.md)**
