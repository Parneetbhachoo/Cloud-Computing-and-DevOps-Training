
# Week 3: DevOps Tools (Git + CI/CD Basics)

## Overview
Week 3 focused on understanding essential DevOps tools and practices, including version control using Git, collaboration through GitHub, and the fundamentals of Continuous Integration and Continuous Delivery/Deployment (CI/CD). The week also introduced Jenkins and its role in automating software build processes through pipelines.

## Topics Covered

### 1. Version Control Using Git
- Introduction to version control and its importance in software development.
- Understanding Git as a distributed version control system.
- Creating and managing a GitHub repository.
- Tracking changes and maintaining project history.

### 2. GitHub Workflow
- Understanding the basic GitHub workflow.
- Cloning repositories to work on projects locally.
- Committing changes with meaningful commit messages.
- Pushing local changes to a remote GitHub repository.
- Understanding pull requests and their role in collaborative development.

### 3. Introduction to CI/CD
- Understanding Continuous Integration (CI) and Continuous Delivery/Deployment (CD).
- Learning how CI/CD helps automate software development workflows.
- Introduction to the concept of pipelines.
- Understanding the role of automation in improving development efficiency and consistency.

### 4. Jenkins Basics
- Introduction to Jenkins as an automation server.
- Understanding Jenkins and its role in CI/CD workflows.
- Learning the basic concept and structure of a Jenkins pipeline.
- Understanding how Jenkins can automate repetitive development tasks.

### 5. Jenkins Pipeline Setup
- Introduction to setting up a Jenkins pipeline.
- Understanding the stages involved in a pipeline.
- Exploring how pipeline stages can organize and automate build tasks.

### 6. Automating the Build Process
- Understanding the purpose of build automation.
- Learning how automated builds can be triggered as part of a development workflow.
- Understanding how CI/CD tools help reduce manual effort and improve consistency.

## Learning Objectives
By the end of Week 3, the key learning objectives were to:

- Understand the fundamentals of version control using Git.
- Create and manage repositories on GitHub.
- Understand the clone, commit, push, and pull request workflow.
- Explain the basic concepts of CI/CD and pipeline automation.
- Understand the role of Jenkins in automating development workflows.
- Learn the fundamentals of Jenkins pipeline setup.
- Understand how build processes can be automated using DevOps tools.


## Week Summary
Week 3 introduced the core tools and concepts used in modern DevOps workflows. Git and GitHub provided the foundation for version control and collaboration, while CI/CD concepts and Jenkins demonstrated how software development tasks can be organized into pipelines and automated. These concepts form an important foundation for building efficient and repeatable software delivery workflows.
