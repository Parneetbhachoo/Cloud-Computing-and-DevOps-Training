
# Day 01 — Introduction to Cloud Computing and DevOps

## 1. Overview
The first day of the Master Class Program on Cloud Computing and DevOps focused on understanding the fundamentals of Cloud Computing, different computing models, major cloud service providers, and commonly used DevOps and project management tools.

## 2. Topics Covered

### 2.1 Fundamentals of Cloud Computing and DevOps
- Introduced the core concepts of Cloud Computing and DevOps.
- Understood the role of cloud infrastructure in providing computing resources and services over the internet.
- Explored how DevOps practices help improve collaboration, automation, and software delivery.

### 2.2 Computing Models
Studied the characteristics and differences between the following computing models:

- **Standalone Computing:** A computer operates independently and performs tasks using its own resources.
- **Client-Server Computing:** Clients request services or resources from a centralized server.
- **Distributed Computing:** Multiple interconnected computers work together to perform tasks and share resources.
- **Cloud Computing:** Computing resources, such as servers, storage, and applications, are delivered over a network on demand.

### 2.3 Major Cloud Platforms
Explored the features and purposes of major cloud service providers:

- **Amazon Web Services (AWS)**
- **Microsoft Azure**
- **Google Cloud Platform (GCP)**
- **IBM Cloud**

Studied their role in providing cloud infrastructure, storage, computing services, and application hosting.

### 2.4 DevOps and Project Management Tools
Received an introduction to tools commonly used in software development, deployment, collaboration, and project management:

- **Vercel:** A platform for deploying and hosting web applications.
- **Asana:** A tool for task management and team collaboration.
- **Trello:** A visual task management tool based on boards, lists, and cards.
- **Jira:** A project management and issue-tracking tool widely used by software development teams.
- **Bitbucket:** A Git-based code hosting and collaboration platform.

## 3. Key Learnings
- Understood the fundamental concepts of Cloud Computing and DevOps.
- Identified the differences between standalone, client-server, distributed, and cloud computing.
- Became familiar with major cloud platforms and their practical applications.
- Learned about tools used for application deployment, version control, task tracking, and team collaboration.
- Developed an introductory understanding of how cloud services and DevOps tools support modern software development workflows.

## 4. Outcome
Gained foundational knowledge of computing models, cloud service providers, and DevOps-related tools, establishing a basis for exploring Linux, networking, cloud infrastructure, and automation in subsequent training sessions.
